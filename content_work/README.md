# content_work

Working files for editorial-original content — prompts and explainers.

`ai-news content template` writes a skeleton here; a Claude Code session fills it in;
`ai-news content validate` and `ai-news content import` read it back.

**The JSON files are git-ignored.** They hold unpublished editorial drafts, which belong
in the database and in review, not in version control. Only this README is tracked — the
same rule as `editorial_work/` and `writing_work/`.
