# Writing working directory

`ai-news draft export` writes assignment files here, and finished draft JSON is written
alongside them.

The JSON files are **git-ignored**. They are working artefacts; the drafts they produce
live in SQLite once imported, and those are the record.

See [CLAUDE_WRITING_WORKFLOW.md](../CLAUDE_WRITING_WORKFLOW.md) for the loop and
[docs/telegram_style_guide.md](../docs/telegram_style_guide.md) for the voice.
